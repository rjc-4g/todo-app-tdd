# todo-app-tdd

## Overview
TODO管理Webアプリケーション<br>
TDDの習得を主眼に、React/Goで作成する

【立ち上げ手順】<br>
以下のコマンド実行<br>
cd {各配置場所}\todo-app-tdd<br>
docker compose up -d

以下のURLにアクセス<br>
http://localhost:3000/

【テストコード実行手順】<br>
以下のコマンド実行<br>
docker compose exec backend go test -v
